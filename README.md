# ⚡ ZENITH Executor

> A modern, lightweight Roblox Lua script executor built with Python and CustomTkinter.

![Version](https://img.shields.io/badge/version-2.0-blue)
![Python](https://img.shields.io/badge/python-3.11+-green)
![License](https://img.shields.io/badge/license-MIT-orange)

## 🚀 Features

- 💻 **Clean, modern UI** with dark theme and custom title bar
- 📄 **Tabbed script editor** with line numbers
- 💾 **Save/Load scripts** locally
- ☁️ **Script Hub** integration (search & load from ScriptBlox)
- 🛠️ **Tools** section with popular scripts (Infinite Yield, Dex, etc.)
- ⚙️ **Settings** (theme, always on top, kill Roblox, flush RAM)
- 🔌 **DLL injection** with proper exports (`initialize`, `attach`, `execute`)
- 🖱️ **Draggable top bar** and rounded corners
- 🔍 **Auto-detects** Roblox process
